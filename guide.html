Guide

Connect an exchange (read-only)

  1. On the exchange, open API management and create a new API key.
  2. Turn on read permission only. Leave trading and withdrawal off.
  3. In Fillview, tap Positions → Connect, pick the exchange and paste the key. DEXs like Hyperliquid need only your wallet address.

Change your referral

  1. Centralized exchanges (Bybit, Bitget, OKX) don’t let you change the referrer of an existing account, and identity checks usually block a second account.
  2. So the easiest path is an exchange you don’t use yet, opened through our link.
  3. On DEXs (Aster, Ondo Perps) a new wallet is a new account: create a wallet → open our referral link → move your funds.

Stay safe

  • Never share your seed phrase or API secret with anyone — including us.
  • Fillview never asks you to sign transactions or send funds. If something does, it isn’t us.
